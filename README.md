# 🏏 IPL Franchise Game

A browser-based IPL franchise management and auction simulation game.

## 🎮 Play the Game

https://ipl-franchise-game.vercel.app/

## 🔥 IPL Auction Game

Play an IPL-style franchise auction where you manage your budget, bid for players and build your squad.

https://ipl-franchise-game.vercel.app/ipl-auction-game

## 🎯 IPL Auction Simulator

Run your own IPL-style auction, manage your purse and build a competitive franchise.

https://ipl-franchise-game.vercel.app/ipl-auction-simulator

## Features

- 🏏 IPL-style player auctions
- 💰 Franchise purse management
- 👥 Squad building
- 📋 Playing XI management
- 🔄 Player trades
- 🌱 Youth academy
- 🏆 Challenges
- 🧠 What-if simulations
- 📊 Standings
- 🎮 Multi-season franchise management
- ⚡ Ball-by-ball tactical simulation

## About

IPL Franchise Game is an independent browser-based cricket franchise
simulation project focused on auction strategy, squad management and
long-term franchise building.
